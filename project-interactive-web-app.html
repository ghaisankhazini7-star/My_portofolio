About this project

Moomentum Mind — Design Agency Website

A fully interactive website built for Moomentum Mind, the design agency community I'm part of as a Software Engineer. The site showcases the team, services, and brand identity.

Built with pure HTML, CSS, and JavaScript — featuring smooth scroll animations, a loading screen, page transitions, and sections for About, Services, Team, and Contact.

This project taught me how to build a real-world client-facing website from scratch — balancing design, performance, and interactivity all in one.
