About this project

Bringing interfaces to life with motion

Successfully integrated Lottie animations into a live web project — adding professional-quality motion that makes the interface feel more alive and responsive.

This project was my first serious experiment with motion design. I learned how animation timing, easing, and micro-interactions can completely change how a user feels when using a product.

Everything was built with attention to performance — animations that are smooth, lightweight, and purposeful rather than just decorative.
