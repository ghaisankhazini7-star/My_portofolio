Vegbals — Vegetable Center App

Vegbals is a mobile shopping app that helps users find and buy fresh vegetables with ease. Its clean interface is designed to feel clear, modern, and simple to navigate.

Designed in Figma, the app uses clear hierarchy, consistent color, and familiar interactions to guide users through every screen.

A shared style guide keeps the 30+ screens consistent and makes the system easy to expand.

About this project

A complete design system built in Figma

A collection of reusable UI components built in Figma: buttons, cards, navbars, inputs, and more, organized for easy use in future web projects.

Each component follows the same spacing, color, and typography rules, creating a foundation that is both consistent and scalable.

The project shows how a strong design system can make interface work faster, clearer, and more consistent.
